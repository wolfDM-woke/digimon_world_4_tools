# digimon_world_4_tools
useful tools for logging data
fully finished tools:
1. warp menu tp (`warp_menu/`): Gecko code to warp to any of 83 rooms, with an optional on-screen overlay
2. deglaze (`deglaze/`): finds "matched" decomp functions that are really copied asm
3. mods (`mods/`): spin2win v3 and aim assist Gecko codes

Also: `permuter-rolling-tools/`, rolling and tie_merge config files for decomp-permuter.

All Gecko codes here are for the USA release only (GDJEB2).
